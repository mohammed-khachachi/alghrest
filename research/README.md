# Research

- `hmm_trading/`: current independent educational Hidden Markov Model study. Run from this directory with its own environment, `requirements.txt`, and test configuration.
- `hmm_legacy/`: older implementation with unique code, reports, and reference material. Retained for comparison; not part of the application runtime.

Do not import either project from `src/` at the repository root. Do not merge their dependencies into the trading environment. See [development workflow](../docs/monorepo-workflow.md) and the [integration roadmap](../docs/integration-roadmap.md).
