# Optional References

ضع هنا ملف Stanford Hidden Markov Models PDF إذا توفر لاحقاً. هذا المجلد
اختياري، والمشروع الحالي لا يحتاج إلى وجود الملف حتى يعمل.

مثال اسم الملف:

```text
Stanford_Hidden_Markov_Models.pdf
```

بعد إضافة الملف، شغل البحث من داخل مجلد `project/`:

```powershell
python src/file_finder.py
```

إذا لم يوجد الملف، سيستمر المشروع بالاعتماد على المفاهيم النظرية القياسية
لنماذج HMM دون تعديل التقرير أو الادعاء بوجود مصدر غير متوفر.
