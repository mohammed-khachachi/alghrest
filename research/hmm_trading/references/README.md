# مراجع مشروع HMM

الملف الموجود حاليًا في المستودع الخاص هو:

[Stanford_Hidden_Markov_Models.pdf](Stanford_Hidden_Markov_Models.pdf)

يبحث `src/references/finder.py` عن مرجع HMM، ثم يحاول
`src/references/extractor.py` استخراج النص بواسطة `pypdf`، وبعده `PyMuPDF`.
إذا لم يجد الملف أو تعذر استخراج النص، يستخدم الملخص النظري المضمّن في
الشفرة. راجع رسائل التشغيل لمعرفة المصدر الذي استُخدم فعليًا.

يُحفظ النص الناتج محليًا في
`outputs/extracted_text/stanford_hmm_extracted.txt`؛ هذا مخرج مولّد وليس المرجع
الأصلي، وهو غير منشور ضمن ملفات المشروع الحالية.

مواقع المقررات الرسمية:

- [Stanford CS229](https://cs229.stanford.edu/)
- [Stanford CS228](https://cs228.stanford.edu/)

وجود المرجع أو استخراج نصه لا يثبت صحة استراتيجية تداول أو نتائج خارج العينة.
احتفظ بمصدر المراجع وحقوق استخدامها، ولا تستبدلها ببيانات سوق خاصة أو مفاتيح.
للتشغيل والتحقق، اتبع [README المشروع البحثي](../README.md).
