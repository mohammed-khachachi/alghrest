## 1. تحليل إطار Stanford للنماذج الاحتمالية

### 1.1 نظرة عامة على مواد Stanford HMM

تُقدّم مواد Stanford (CS229 / CS228) نماذج ماركوف المخفية كأحد أهم أدوات النمذجة الاحتمالية للبيانات المتسلسلة. تبني هذه المواد على النقاط الآتية:

- **الاستقلالية الشرطية (Conditional Independence):** المستقبل مستقل عن الماضي بمعرفة الحاضر — وهو ما يُعرف بـ Markov Assumption.
- **البنية الهرمية:** الحالات المخفية تولّد الملاحظات المرئية عبر توزيعات الانبعاث.
- **التعلم غير الخاضع للإشراف (Unsupervised Learning):** يمكن تدريب HMM بدون أي تسميات.
- **ثلاث مسائل جوهرية:** التقييم (Evaluation)، والترميز (Decoding)، والتعلم (Learning).

### 1.2 جدول تحليل المفاهيم وتطبيقاتها المالية

| **مفهوم HMM** | **المعنى النظري (Stanford)** | **التطبيق في التداول الكمي** |
|:---|:---|:---|
| Hidden State (s_i) | حالة غير مرئية تؤثر على الملاحظات | حالة السوق: صاعد، هابط، جانبي، عالي التقلب |
| Observation (o_t) | بيانات مرئية تنتج عن الحالة المخفية | العائد اليومي، التقلب، نسبة المتوسطات، حجم التداول |
| Initial Distribution (π) | P(q_1 = s_i) — احتمال البدء في كل حالة | احتمالية كون السوق في أي نظام عند بداية التحليل |
| Transition Matrix (A) | P(q_{t+1} \| q_t) — احتمال الانتقال | احتمال انتقال السوق من صعود إلى ضغط مثلاً |
| Emission (Gaussian B) | P(o_t \| q_t) — توزيع الملاحظات | توزيع العوائد ضمن كل نظام سوقي |
| Markov Assumption | قصير الذاكرة: المستقبل ≈ f(الحاضر) | النظام السوقي الحالي يكفي للتنبؤ بالانتقال التالي |
| Forward Algorithm (α) | P(O\|λ) — احتمال تسلسل الملاحظات | تقييم مدى توافق بيانات السوق مع النموذج |
| Viterbi Algorithm | argmax_Q P(Q\|O,λ) — أفضل مسار | استخراج أكثر تسلسل محتمل لحالات السوق عبر التاريخ |
| Baum-Welch (EM) | تعلم A، B، π من البيانات | تدريب النموذج على بيانات السوق بدون تسميات |
| Backward Algorithm (β) | β_t(i) = P(o_{t+1},...,o_T \| q_t=s_i) | يُستخدم داخل Baum-Welch لحساب γ و ξ |

## 2. الخلفية النظرية لنماذج ماركوف المخفية

### 2.1 التعريف الرياضي

نموذج ماركوف المخفي هو نموذج احتمالي للبيانات المتسلسلة يتكوّن من:

**الفضاء الرياضي:**

```
λ = (S, O, π, A, B)
```

حيث:
- **S = {s₀, s₁, ..., s_{N-1}}** : مجموعة الحالات المخفية (finite hidden states)
- **O = {o₀, o₁, ..., o_{T-1}}** : متتالية الملاحظات المرصودة
- **π_i = P(q₁ = s_i)** : توزيع الحالة الابتدائية
- **A_{ij} = P(q_{t+1} = s_j | q_t = s_i)** : مصفوفة الانتقال
- **B_i(o_t) = P(o_t | q_t = s_i)** : دالة توزيع الانبعاث

### 2.2 افتراض ماركوف (Markov Assumption)

```
P(q_t | q_{t-1}, q_{t-2}, ..., q₁) = P(q_t | q_{t-1})
```

**التطبيق المالي:** نظام السوق الحالي (صاعد / هابط / جانبي) يُحدّد بشكل أساسي احتمالية نظام الغد، بغضّ النظر عن حالة الشهر الماضي. هذا تبسيط لكنه مفيد تطبيقياً.

### 2.3 المسائل الثلاث الجوهرية (Three Fundamental Problems)

#### المسألة الأولى: التقييم — خوارزمية Forward

**السؤال:** ما احتمالية ملاحظة التسلسل O تحت النموذج λ؟

$$\alpha_t(i) = P(o_1, ..., o_t, q_t = s_i | \lambda)$$

**الحساب التكراري:**
```
α₁(i) = π_i · B_i(o₁)
α_t(j) = [Σ_i α_{t-1}(i) · A_{ij}] · B_j(o_t)
P(O|λ) = Σ_i α_T(i)
```

**الاستخدام في التداول:** تقييم مدى توافق بيانات السوق الجديدة مع النموذج المدرَّب — يمكن استخدامه للكشف عن تغييرات هيكلية في السوق.

#### المسألة الثانية: الترميز — خوارزمية Viterbi

**السؤال:** ما أكثر تسلسل للحالات المخفية احتمالاً يُفسّر الملاحظات؟

$$Q^* = \arg\max_Q P(Q | O, \lambda)$$

**الحساب:**
```
δ₁(i) = π_i · B_i(o₁)
δ_t(j) = [max_i δ_{t-1}(i) · A_{ij}] · B_j(o_t)
```

**الاستخدام في التداول:** تحديد النظام السوقي (Regime) لكل يوم تداول تاريخياً — أساس بناء الإشارة.

#### المسألة الثالثة: التعلم — خوارزمية Baum-Welch (EM)

**السؤال:** كيف نتعلم معاملات λ = (A, B, π) من البيانات؟

```
خطوة E: احسب  γ_t(i) = P(q_t = s_i | O, λ)
          و    ξ_t(i,j) = P(q_t=s_i, q_{t+1}=s_j | O, λ)

خطوة M: حدّث  π_i = γ₁(i)
          A_{ij} = Σ_t ξ_t(i,j) / Σ_t γ_t(i)
          μ_i = Σ_t γ_t(i) · o_t / Σ_t γ_t(i)
          Σ_i = Σ_t γ_t(i) · (o_t-μ_i)(o_t-μ_i)ᵀ / Σ_t γ_t(i)
```

**الاستخدام في التداول:** تدريب النموذج من بيانات السوق التاريخية بدون أي تسمية يدوية للأنظمة.

## 3. لماذا السوق المالي نظام HMM؟

### 3.1 طبيعة الأسواق كأنظمة حالات مخفية

الأسواق المالية تُظهر خصائص تجعلها متوافقة مع إطار HMM:

**الحالات غير المرصودة مباشرةً:**
لا يمكن ملاحظة "نظام السوق" مباشرةً — لا يوجد مؤشر رسمي يقول "السوق صاعد الآن". ما نراه هو فقط الأسعار والأحجام والعوائد.

**انتقالات الأنظمة (Regime Transitions):**
السوق ينتقل بين أنظمة مميزة: صعود هادئ، تراجع متسارع، تذبذب جانبي، انهيار حاد. هذه الانتقالات تتبع نمطاً احتمالياً يشبه مصفوفة Transition في HMM.

**التوزيعات المختلفة عبر الأنظمة:**
في فترات الصعود: العوائد موجبة بتقلب منخفض (B_bullish).
في فترات الأزمات: العوائد سالبة بتقلب مرتفع جداً (B_bearish).
هذا يُترجَم مباشرةً لـ Gaussian Emission Distributions مختلفة.

### 4.4 استخراج الأنظمة (Viterbi Decoding)

بعد التدريب، يُطبَّق خوارزمية Viterbi لاستخراج أكثر تسلسل محتمل:

```
Q* = [0, 0, 1, 1, 2, 1, 0, 0, 2, ...]
```

كل رقم يمثل نظاماً سوقياً ليوم تداول محدد.

### 4.5 تفسير الأنظمة (Regime Interpretation)

يُفسَّر كل نظام بناءً على إحصاءاته:

| **الحالة** | **متوسط العائد** | **متوسط التقلب** | **الوصف** |

| State 0 | موجب > 0.03% | منخفض < 15% | Bullish / Low-Vol |
| State 1 | سلبي < -0.03% | مرتفع > 20% | Bearish / High-Vol |
| State 2 | قريب من صفر | متوسط 12-20% | Sideways / Moderate-Vol |

*ملاحظة: التسمية تعتمد على الإحصاءات الفعلية للنموذج المدرَّب، وقد تختلف.*

### 4.6 استراتيجية التداول

```
القاعدة البسيطة:
  إذا كانت الحالة "Bullish" وتقلب "Low أو Moderate" → LONG (شراء)
```

## 6. نقاط القوة والضعف والمخاطر

### 6.1 نقاط القوة

**نقطة 1 — التعلم غير المُشرف (Unsupervised):**
لا حاجة لتسمية يدوية للأنظمة — النموذج يكتشفها تلقائياً من البيانات.

**نقطة 2 — الأساس الاحتمالي المتين:**
مبني على إطار رياضي صارم (Baum-Welch، Viterbi) مع ضمانات نظرية معروفة.

**نقطة 3 — التفسيرية (Interpretability):**
كل نظام له إحصاءات واضحة (متوسط العائد، التقلب) تجعله قابلاً للتفسير البشري.

**نقطة 4 — المرونة (Flexibility):**
يمكن تغيير عدد الحالات، وأنواع الخصائص، والورقة الزمنية بسهولة.

### 6.2 نقاط الضعف

**نقطة 1 — عدم الاستقرار (Non-Stationarity):**
الأسواق تتغير بنيتها عبر الزمن. نموذج مدرَّب على 2010-2020 قد لا يُعمَّم على 2021-2024.

**نقطة 2 — الحساسية لعدد الحالات:**
اختيار N=3 تحكمي. لا توجد طريقة موضوعية مثلى لاختيار العدد.

**نقطة 3 — الحساسية للخصائص:**
نتائج النموذج حساسة لأي تغيير في الخصائص المُستخدَمة.

**نقطة 4 — التأخر في الاكتشاف (Regime Lag):**
HMM يحدد الأنظمة بعد وقوعها — لا يتنبأ بها مسبقاً.

### 6.3 المخاطر الجوهرية

**مخاطر التجاوز (Overfitting):**
الباكتيست في العيّنة يبالغ في التفاؤل. التحقق الحقيقي يستلزم Walk-Forward Analysis.

**مخاطر انتهاك الافتراضات:**
HMM يفترض Markov Property وتوزيعات Gaussian — كلاهما غير مضمون في الأسواق الحقيقية.

**مخاطر التنفيذ (Execution Risk):**
التكاليف الحقيقية (spread، slippage، market impact) أعلى من الرسوم المبسطة المُستخدمة.

## 7. حدود المشروع (لذكرها أمام المُقيِّم)

1. **الباكتيست داخل العيّنة (In-Sample):** التدريب والاختبار على نفس البيانات يُضخّم النتائج.
2. **لا Walk-Forward:** التحقق الحقيقي يستلزم اختبار خارج العيّنة.
3. **لا تكاليف واقعية:** الأسواق الحقيقية لها Spread وSlippage غير محسوبة.
4. **N=3 تحكمي:** AIC/BIC يُوصى بها لاختيار عدد الحالات.
5. **لا Short:** النسخة الأولى تعمل بـ Long/Cash فقط.
6. **بيانات يومية فقط:** HMM يمكن تطبيقه على بيانات أقل من يومية (intraday) بتعديلات.
7. **ملف Stanford:** بُني المشروع على المعرفة المدمجة لإطار Stanford، لم يُحمَّل الملف الأصلي.

## 8. أفكار التطوير المستقبلي

### المرحلة الثانية (Mid-Level)
- تطبيق **Walk-Forward Analysis** لتقييم خارج العيّنة الحقيقي
- تجربة عدد حالات مختلفة (2 إلى 6) باستخدام **BIC / AIC**
- إضافة **أصول متعددة** (سندات، ذهب، BTC) للتنويع
- تطبيق **تكاليف معاملة واقعية** (bid-ask spread)

### المرحلة الثالثة (Advanced)
- **Regime-Aware Portfolio Optimization:** تخصيص الوزن بحسب النظام
- **Online Learning:** تحديث النموذج تدريجياً مع وصول بيانات جديدة
- **Hidden Semi-Markov Models (HSMM):** نمذجة مدة الإقامة في كل نظام
- **Regime Switching GARCH:** دمج HMM مع نماذج التقلب
- **Ensemble Approaches:** جمع HMM مع LSTM أو Random Forest

### الشريحة 4: المعادلة
```
P(q_t | q_{t-1}) = A_{q_{t-1}, q_t}     ← Markov Property
P(o_t | q_t)     = N(o_t; μ_{q_t}, Σ_{q_t})  ← Gaussian Emission
```

## 10. أسئلة متوقعة من المُقيِّم وإجاباتها

**س: لماذا اخترت 3 حالات؟**  
ج: يعكس الأنظمة الثلاثة الأكثر تكراراً: صعود، هبوط، تذبذب. يمكن استخدام BIC أو AIC لاختيار العدد الأمثل.

**س: كيف تتحقق من أن النموذج فعلاً اكتشف أنظمة سوقية وليس ضوضاء؟**  
ج: بفحص إحصاءات كل حالة — يجب أن تُظهر متوسط عوائد وتقلبات مميزة إحصائياً.

**س: ما الفرق بين Viterbi وForward Algorithm؟**  
ج: Viterbi يجد أفضل مسار كامل للحالات (argmax)، بينما Forward يحسب احتمالية تسلسل الملاحظات (مجموع).

**س: هل النموذج يتنبأ بالسوق؟**  
ج: لا. HMM يصف الأنظمة ويكتشف الحالة الحالية — لا يتنبأ بالسعر. إنه أداة وصفية وتصنيفية.

**س: ما مشاكل Look-Ahead Bias في مشروعك؟**  
ج: النموذج مدرَّب على كامل التاريخ (In-Sample) — هذا يُدخل تحيزاً. الحل الحقيقي هو Walk-Forward.

**س: لماذا Gaussian Emission وليس Discrete؟**  
ج: خصائص السوق (عوائد، تقلب) مستمرة (continuous) وتُقرَّب بشكل معقول بتوزيع Gaussian ضمن كل نظام.
