# Configuration

`default.json` is the baseline HMM trading experiment. It is loaded by `src/core/config.py::load_config` and validated by `validate_config` before being passed into `src/pipeline/runner.run(config)`.

To use a different file, pass it explicitly:

```powershell
python main.py --config configs/my_experiment.json
```

## Fields

### Data window

- `ticker` — Market symbol used for data retrieval. Unsupported or unavailable symbols fall back to synthetic data generated by `src/data/synthetic.py`.
- `start` — Inclusive start date for the historical sample (`YYYY-MM-DD`).
- `end` — End date passed to the data provider for the historical sample (`YYYY-MM-DD`).

### HMM training

- `n_states` — Number of hidden regimes fitted by the Gaussian HMM.
- `covariance_type` — Covariance structure passed to `hmmlearn.hmm.GaussianHMM` (`full`, `diag`, `tied`, `spherical`).
- `n_iter` — Maximum Baum-Welch training iterations.
- `random_state` — Seed used to make model fitting reproducible.

### Backtest

- `transaction_cost` — Per-side cost deducted when the educational signal changes position.
- `trading_days_per_year` — Annualization factor used by backtest metrics.

### Features

- `feature_cols` — Feature columns selected for the scaled HMM observation matrix.
- `rolling_vol_window` — Window length used for rolling volatility features.
- `ma_fast_window` — Window length used for the fast moving average feature.
- `ma_slow_window` — Window length used for the slow moving average feature.

### Regime labelling thresholds

- `regime_thresholds.return_bullish` — Mean daily return threshold for bullish labels.
- `regime_thresholds.return_bearish` — Mean daily return threshold for bearish labels.
- `regime_thresholds.vol_low` — Annualized volatility threshold for low-volatility labels.
- `regime_thresholds.vol_high` — Annualized volatility threshold for high-volatility labels.

## Output

The resolved config used for a given run is persisted alongside results as `outputs/results/run_config.json`, so every artifact in `outputs/` can be traced back to the exact settings that produced it.
