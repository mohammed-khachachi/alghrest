# Presentation site and static examples

| Example | Purpose |
| --- | --- |
| [Project presentation](project-site/README.md) | Independent Next.js / TypeScript / Tailwind site, Arabic and French |
| [Dashboard preview](dashboard-preview.html) | Static illustrative UI snapshot |

Run the project site using its own README. Open the static dashboard preview
directly in a browser. These are demonstrations, not current
runtime telemetry, market evidence or account state. The maintained UI is
[dashboard/](../dashboard/README.md); the current advisory assistant is documented
[here](../docs/manual-assistant.md).

Examples are excluded from the installable application and Docker application
build. Changes here do not deploy the backend or enable trading. Use the root
[development workflow](../docs/monorepo-workflow.md) for application work.
